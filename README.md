# 📖 Overview

FIT EXP is a browser-based fitness tracker that encourages users to build consistent workout habits through a game-inspired experience.

The application provides personalized onboarding, daily workout missions based on experience level, XP progression, achievements, hydration tracking, focus sessions, and activity history. All user data is stored locally in the browser, allowing progress to persist between sessions.

# 🚀 Installation

Clone the repository

```bash

```

Navigate to the project

```bash

```

Run the application

Simply open **form.html** in your preferred web browser.

No additional dependencies or installation are required.

# 🎮 How It Works

1. Create your fitness profile.
2. Select your experience level.
3. Receive personalized daily workout missions.
4. Complete missions to earn XP and FIT Coins.
5. Unlock achievements and maintain your streak.
6. Track hydration and focus sessions.
7. Review progress through charts and activity logs.

# 💾 Data Storage

FIT EXP stores user data locally using the browser's **Local Storage**, including:

* User Profile
* Daily Missions
* XP & Levels
* Achievement Progress
* Activity History
* Rewards
* Focus Sessions
* Hydration Records
* Application Settings

No external database or server is required.
